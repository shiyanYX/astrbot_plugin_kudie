# 尽孝插件 v2.1.0 - AstrBot 游戏评论生成插件

一个 AstrBot 插件，用于生成热爱游戏、把游戏公司当父亲尽孝风格的游戏深度评论文章。支持贴吧热点搜索 + AI 写作。

## ✨ 功能特性

- 📝 自动生成尽孝风格的游戏深度评论
- 🔍 贴吧热点搜索，实时获取社区讨论（新！）
- 📱 扫码登录，一键配置贴吧 Cookie（新！）
- 🎯 支持任意游戏，不局限于特定游戏
- 🎨 9种内置写作风格 + DIY自定义风格
- 📜 历史记录功能，查看过往生成
- ⏱️ 智能冷却和限流机制
- 🛡️ 输入安全过滤，防止 Prompt Injection
- ⚙️ 完善的配置系统

## 🚀 安装方法

### 方法一：通过 AstrBot 插件商店安装
1. 打开 AstrBot 管理面板
2. 进入插件商店
3. 搜索「尽孝」
4. 点击安装

### 方法二：手动安装
1. 将 `astrbot_plugin_kudie` 文件夹复制到 AstrBot 的 `data/plugins` 目录下
2. 重启 AstrBot
3. 插件自动加载

## 📖 使用方法

### 基础命令

```
/尽孝 游戏名 事件描述 [风格/diy 自定义风格]
```

### 搜索命令（新！）

```
/尽孝搜索 游戏名 事件描述 [风格/diy 自定义风格]
```

### Cookie 管理（新！）

```
/尽孝扫码          # 手机扫描二维码登录贴吧（推荐）
/尽孝登录 BDUSS=xxx STOKEN=xxx   # 手动配置 Cookie
/尽孝缓存 清除/事件/角色          # 管理搜索缓存
```

### 使用示例

```
# 基础用法
/尽孝 鸣潮 有人黑角色

# 搜索贴吧热点（需先登录）
/尽孝搜索 卡拉彼丘 令 一直没出红皮
/尽孝搜索 原神 3.0版本须弥开放 激烈反问

# 使用特定风格
/尽孝 王者荣耀 新英雄上线 数据分析
/尽孝搜索 崩坏星穹铁道 剧情太刀 diy 用鲁迅的口吻写
```

### 其他命令

- `/尽孝风格` - 查看所有可用风格
- `/尽孝历史` - 查看您的生成历史
- `/尽孝清除` - 清除您的历史记录
- `/尽孝状态` - 查看插件和个人状态

使用 `diy` 关键字加上你的风格描述：

```

/尽孝 游戏 事件 diy 模仿新闻联播播音员
/尽孝 游戏 事件 diy 用 Rap 歌词的形式
```

## ⚙️ 配置说明

在 AstrBot 管理面板中可以配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| default_style | 默认写作风格 | 默认 |
| system_prompt | 自定义系统提示词 | - |
| enable_history | 启用历史记录 | true |
| max_history_per_user | 每用户最大历史记录数 | 10 |

搜索相关配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| search_query_mode | 搜索词优化模式（llm/raw） | llm |
| search_engine | 搜索入口（baidu/tieba） | baidu |
| search_timeout | 搜索超时（秒） | 15 |
| search_max_posts | 最大搜索帖子数 | 10 |
| search_max_comments | 每帖最大评论数 | 5 |
| cache_event_ttl | 事件缓存有效期（秒） | 600 |
| cache_character_ttl | 角色缓存有效期（秒） | 604800 |

## 🔒 安全特性

- **Prompt Injection 防护**：自动过滤危险字符和模式
- **输入长度限制**：防止超长输入导致的问题
- **冷却机制**：防止 API 滥用
- **限流机制**：每小时请求次数限制
- **错误处理**：友好的错误信息，不暴露内部细节
